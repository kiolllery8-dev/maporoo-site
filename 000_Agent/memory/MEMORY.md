### 2026-08-05 內容策略（推翻原版系統的核心規則）

**部落格文章零商品置入。** 不提商品名、不放商品連結、沒有相關商品區塊、不寫擦邊推薦。

- 部落格寫四種：日常保健（怎麼吃、身體會怎樣）／名人醫師經驗轉述／醫美趨勢科普（為什麼這個成分紅）／生活推薦（哪裡好玩好吃，待確認）
- 老闆給的標準範例：藍心湄掉髮 → 檢查發現營養不良 → 醫師建議每天吃八顆蛋（有知識性、有話題性、容易被模仿）
- 醫美趨勢文寫到「PDRN 為什麼這麼夯——因為診所在用」為止，**不往下寫成推薦我們的商品**
- 流量怎麼變業績？**只剩兩座橋**：**再行銷受眾池（06）** 與 **品牌字回搜（08）**
  - **電子報訂閱已取消**（2026-08-05 同日老闆追加決定）。首頁區塊與 `app/components/Newsletter.tsx` 已刪除
  - 07 會員經營部因此不做獲客，只做已成交客人的關係經營
  - 已知代價：兩座橋都慢，部落格在相當長一段時間內看不到直接業績回報。**這不是執行失敗**
- **部落格的 KPI 是流量與品牌字，不是轉換率**——拿轉換率評判知識文會逼寫手偷偷置入
- 連帶決定：文章資料結構不設 `relatedProducts` 欄位；產品頁也不反向連文章（雙向都不連）
- 連帶風險：轉述名人／醫師說法需標明可查證出處 ＋ 附非醫療建議聲明（見 `compliance-redlines.md` 第六節）
