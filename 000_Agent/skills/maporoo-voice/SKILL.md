# maporoo-voice — 用 MAPOROO 的方式說話

## 五個定案（老闆 2026-08-05 拍板，不可自行更動）

| # | 決定 | 內容 |
| :-- | :-- | :-- |
| 1 | **距離感** | 專業顧問感——先給結論 → 再給原理 → 附上邊界 |
| 2 | **人稱** | 對讀者用「**你**」；品牌自稱用「**MAPOROO**」，不用「我們」當主詞 |
| 3 | **術語深度** | **一律淺**。不出現英文學名、分子量、濃度、文獻引用。淺的是用詞，不是思考 |
| 4 | **情緒溫度** | **分線**：功效線（修復／亮白／保濕／頭皮）理性；香氛線感性可寫畫面 |
| 5 | **標題** | **混用**：搜尋文用問句公式；品牌文與香氛文用斷言句 |
| 6 | **AI 腔** | **全面禁止**。直接說怎麼做、說它是什麼（見下方清單） |
| 7 | **通路** | 官網＋社群同一個聲音；**廣告可以更直白**（放寬句子長度，宣稱尺度一格都不放） |
| 8 | **醫美定位** | 成分講**來源場景**（診所在用的成分）、商品講**使用情境**（療程期間也能用）。**「等級」一律不碰** |

## 醫美怎麼講（定版）

| 講什麼 | 怎麼講 | 範例 |
| :-- | :-- | :-- |
| 成分 | 被用在哪裡 | 「PDRN，醫美診所在用的修護成分」 |
| 商品 | 什麼時候用得上 | 「適合各種膚況，療程期間也能用」 |

一律不碰：醫療級、醫美級、療程級、藥用、處方級、院線級。

## AI 腔清單（對外文案出現即退稿）

| 句型 | 壞例 | 改成 |
| :-- | :-- | :-- |
| 否定對比句 | 「重點不是加強，而是減法」 | 「重點是減法」 |
| 用否定解釋做法 | 「別急著加強保養，因為加強沒用」 | 「先把步驟減到三步」 |
| 因為⋯所以⋯ | 「因為屏障在重建，所以要溫和」 | 「屏障正在重建，這時候溫和一點」 |
| 「你可以⋯」 | 「你可以試著減少步驟」 | 「把步驟減到三步」 |
| 「這樣」收尾 | 「⋯就好，這樣屏障才會穩定」 | 「⋯，屏障會慢慢穩下來」 |
| 倒推句 | 「我不會這樣做，因為沒效，所以要那樣做」 | 「這樣做就好」 |

交稿前搜這六個詞：**不是／而是／因為／所以／這樣／你可以**。搜到就重寫那一句。
然後念出聲——像人在講話，過；像簡報摘要，重寫。

## 執行步驟

1. **先讀 DNA**：`000_Agent/knowledge/maporoo-brand-dna.md`（世界觀、語言指紋、內容分流、視覺）
2. **確認載體與線別**：功效線還是香氛線？部落格還是商品頁？——這兩件事決定寫法
3. **依五個定案下筆**
4. **產出後自檢**，三題全過才交稿：
   - 這段內容有讓讀者**更懂一點**嗎？
   - 有給他一個**今天就能做**的建議嗎？
   - 有**誠實說出邊界**（不適用者、何時就醫、數據條件）嗎？
5. **三支柱過磅**：Ma（原理有講對嗎）／Po（有沒有嚇讀者）／Roo（是催促還是陪伴）
6. **紅線快篩**：對照 `000_Agent/knowledge/compliance-redlines.md` 第二節黑名單，先自刪再送審

## 載體語調速查

| 載體 | 語調重點 | 能不能提商品 |
| :-- | :-- | :-- |
| **部落格知識文** | 顧問感；結論先說；淺術語；問句標題 | ❌ **絕對不行**（見 DNA 第三節） |
| **商品頁（功效線）** | 理性。一句話定位 → 誰適合 → 全成分 → 原理 → 使用步驟 | ✅ 這裡才賣 |
| **商品頁（香氛線）** | 感性。可寫畫面、時間、感受；香調結構用敘事帶 | ✅ 這裡才賣 |
| **社群貼文** | **與官網同一個聲音**。一則一知識點；句子短一些，說法一樣；結尾導回官網 | 依貼文性質，知識型貼文比照部落格 |
| **EDM / LINE** | 顧問寄信感；教育：推銷 ≈ 3:1 | ✅ 可，但教育段落不置入 |
| **廣告** | **可以更直白**：句子更短、一句一重點、開頭直接切入處境。**宣稱尺度一格都不放寬** | ✅ 可 |
| **影音腳本** | 語速沉穩、旁白解說感、開頭同理不恐嚇 | 依內容性質 |

## 兩條線的示範

**功效線（理性）**

> 肌膚疲憊的時候，保養做少一點就好。
> PDRN 安撫泛紅與緊繃，支持肌膚自己修復。

**香氛線（感性）**

> 佛手柑開場，像清晨推開窗的那一瞬。
> 線條往中間走，綠意草本接住，最後落在白木質的溫度上。

## 句子的形狀（照抄）

- 短句、句號結尾、幾乎不用驚嘆號
- 使用步驟一律三步、動詞開頭
- 中英雙軌版面：中文標題 ＋ 全大寫英文 eyebrow
- 「適合各種膚況」是態度句，不只是文案

## 絕不做的事

- 部落格文章裡出現商品名、商品連結、擦邊置入
- 販賣焦慮、誇大保證、療效宣稱（法遵紅線）
- 「醫療級」「醫美級」「療程級」等身分誤導用語
- 浮誇修辭（秒殺、逆天、吹彈可破、嫩白到發光）
- 用「我們」當品牌主詞、用「您」稱呼讀者
- 寫成分時搬出英文學名、分子量、濃度、文獻編號
- 使用前後對比照
- 簡體中文用語（視頻→影片、信息→訊息、質量→品質）
