## 前置

1. 載入 `maporoo-voice` 技能（語調）
2. 拿到選題卡（目標主字、長尾字、搜尋意圖、內容型態）；沒有選題卡就先扮演 01 策略數據部補做
3. 確認產出位置：`/read/[slug]` 路由尚未上線，先寫成 Markdown 存 `000_Agent/output/articles/<slug>.md`

## 四種內容型態（先確認這篇是哪一種）

| 型態 | 寫什麼 | 範例 |
| :-- | :-- | :-- |
| **A 日常保健** | 怎麼吃、吃了身體會怎樣、作息與身體 | 每天吃八顆蛋會怎樣？ |
| **B 名人／醫師經驗轉述** | 有話題性的真實案例 ＋ 原理解釋 | 藍心湄的掉髮與營養不良 |
| **C 醫美趨勢科普** | 某成分／療程為什麼紅，只講現象與原理 | PDRN 最近為什麼這麼夯？ |
| **D 生活推薦** | 哪裡好玩、哪裡好吃 | ⚠ 待老闆確認是否啟動 |

## 生產步驟

### Step 1 標題（問句公式）

搜尋文一律用這個骨架——它同時是 SEO 武器與合規保險：

```
（疑問句）？（破除迷思的提醒）、（數字化的行動建議）
```

範例：

- 「PDRN 最近為什麼這麼夯？不是新成分、3 件你該先知道的事」
- 「每天吃八顆蛋會怎樣？別急著跟風、5 個先確認的前提」
- 「掉髮一定是壓力大嗎？2 個常被忽略的原因、3 種情況要看醫師」

品牌理念文與香氛文改用斷言句（見 `maporoo-brand-dna.md` 2.5）。

### Step 2 大綱

顧問式順序，每個 H2/H3 對應一組長尾問法（目標：一篇吃 50+ 關鍵字）：

```
H2 結論先說（這篇的重點一句話）
H2 這是什麼／為什麼會這樣（原理）
H2 常見的誤解
H2 什麼情況要問醫師／營養師
H2 可以怎麼做（數字化清單）
H2 FAQ
```

### Step 3 內文（四段式安全結構）

1. **同理開頭**：描述讀者處境，不恐嚇（「你可能也遇過⋯其實這很常見」）
2. **結論段**：先給答案，這是顧問感的核心
3. **原理段**：講對，但用淺的話講。不出現英文學名、分子量、濃度、文獻編號
4. **邊界段**：「這幾種情況請諮詢醫師／營養師」——標配，不可省

### Step 4 出處與聲明（型態 B、C 必做）

- 引用名人說法：標明**節目／媒體名稱、時間、可查證的來源**
- 引用醫師建議：標明**醫師姓名或所屬單位、出處**；查不到出處的說法**不寫**
- 文中必含聲明：「以上為個人經驗分享與知識整理，不是醫療建議。個別狀況請諮詢專業人員。」
- 不確定真偽的傳言，寫成「有這樣的說法，但目前沒有可查證的來源」，**不要當事實寫**

### Step 5 導流（單軌）

- 站內內鏈：連到**其他文章**，建立主題集群
- 文末：延伸閱讀 3 篇，**就這樣**
- ❌ 不放商品連結、不放相關商品區塊、不提商品名
- ❌ 不放電子報訂閱表單（2026-08-05 取消）

### Step 6 自檢與送審

**零置入自檢（任一項中了就退回重寫）**

- [ ] 全文沒有出現任何 MAPOROO 商品名稱
- [ ] 全文沒有 `/products/` 連結

- [ ] 這篇文章拿掉品牌名之後，還像一篇真正的知識文嗎？

**語調自檢**

- [ ] 結論先說 → 原理 → 邊界，順序對
- [ ] 人稱是「你」；提到品牌用「MAPOROO」不用「我們」
- [ ] 沒有英文學名、分子量、濃度、文獻引用
- [ ] 原理有講對（淺的是用詞，不是思考）

**法遵自檢**

- [ ] 無療效宣稱、無誇大保證、無「醫療級」類用語（對照 `compliance-redlines.md`）

- [ ] 涉及症狀或飲食建議 → 有「何時就醫」段落

**SEO 自檢**

- [ ] 主字進標題與首段、H 結構涵蓋長尾、meta description 150 字內
- [ ] 站內內鏈與延伸閱讀齊備
