## 這個資料夾是什麼

把這個 repo 當成一間公司（同時它也是官網的程式碼庫）：

- `../CLAUDE.md` — **雅琪的大腦**：人格、KPI 鐵律、任務路由、決策原則、就任流程

- `workflows/` — **每週迴圈儀式**：`weekly-growth-loop.md`
- `memory/` — **跨 session 記憶**：迴圈學到的事會累積在這裡

## 銷售迴圈（無人行銷的心臟）

```
數據選題 → 教育文章 → 商品承接 → 社群/廣告放大 → 會員回購
   ▲                                                │
   └────────────── 業績與流量回報 ←─────────────────┘
```

為什麼是這個迴圈？因為對標竿品牌綠藤官網的實際拆解顯示（Ahrefs 數據，詳見
`knowledge/website-analysis.md`）：它月自然流量約 8.3 萬，
**流量前 40 名頁面中超過 30 個是「痛點教育文章」**，文章排進 Google 前三名，
再溫柔地把讀者帶往產品頁。教育，就是最便宜的獲客引擎——MAPOROO 照這套打。

## 內容策略：部落格零商品置入（2026-08-05 老闆拍板）

這是本組織最重要的一條規則，也是與原版系統最大的差異：

- 部落格文章**不提商品名、不放商品連結、沒有相關商品區塊、不寫擦邊推薦**
- 寫四種：日常保健（怎麼吃、身體會怎樣）／名人醫師經驗轉述／醫美趨勢科普（為什麼這成分紅）／生活推薦
- 流量怎麼變業績？只靠兩座橋：**再行銷受眾池（06）** 與 **品牌字回搜（08）**（電子報訂閱已取消）
- 兩座橋都慢——部落格短期內看不到直接業績回報，這是策略的已知代價，不是執行失敗
- 部落格的 KPI 是**流量與品牌字**，不是轉換率

完整規則見 `knowledge/maporoo-brand-dna.md` 第三節。

## 語調定案（2026-08-05 訪談）

專業顧問感（結論先說 → 原理 → 邊界）｜對讀者用「你」、品牌自稱「MAPOROO」｜術語一律淺｜
功效線理性、香氛線感性｜搜尋文用問句標題、品牌文用斷言句。

## 上任第一天就會發現的四件事

1. **文章頁的再行銷像素還沒裝**——零置入 ＋ 沒有電子報之後，這是唯一能用錢加速的一座橋
2. **官網沒有部落格**——`/read` 路由不存在，首頁 LIBRARY 六篇是假資料。獲客環節目前等於零
3. **沒有數據基準線**——GA4 / Ahrefs / 電商後台都還沒接，01 部門的第一份週報是「建立基準線」而非環比
4. **法遵風險已經在頁面上**——官網現有文案含「醫療級」「醫美」「嫩白」等高風險用語，門市資訊也待查證（見 `knowledge/compliance-redlines.md` 第五節）
