## 回購迴圈 SOP

```
首購（03 交接商品脈絡）
→ D+3 使用教學信（怎麼用、用多久、常見疑問）——教育，不推銷
→ D+30 知識信（與所購品類相關的教育文章精選）
→ 用量週期尾聲：溫柔補貨提醒（附回購優惠）
   ・精華 30ml 約 6–8 週｜面膜 5 片約 3–5 週｜洗沐髮 300–500ml 約 8–12 週
→ 回購 2 次以上：邀請進入會員專屬內容與新品試用 → 從顧客變成同路人
```

## 工作鐵律

1. 會員訊息的教育：推銷比例維持約 3:1——收件匣裡我們是朋友，不是傳單
2. 分群發送：依購買品類給對應知識（買頭皮線的人收頭皮知識，不收全館轟炸）
3. 電子報**同樣是廣告**，療效宣稱一樣會被罰——所有對外訊息過 04 法遵
4. 退訂要好按，資料要好刪；不玩暗黑模式
