# 01 策略數據部 — 迴圈的起點與終點

> 使命：用數據決定「這週打哪裡」。迴圈從我們的選題開始，也在我們的週報結束。

| 角色 | 專業 | 負責 |

## 第 0 號任務：建立基準線（在做任何環比之前）

MAPOROO 目前**沒有任何實測數據**。第一次被派工時，先做這件事，不要急著給週報：

1. 確認資料源是否可用：GA4 資源 ID、Search Console 權限、電商後台、Ahrefs（本 session 有 Ahrefs MCP 工具可用）
2. 撈出可得的第一組數字，寫進 `knowledge/kpi-dashboard.md` 的基準線區塊：
   - 自然流量／付費流量／社群／直接（月）
   - 排名關鍵字數、前三名數、品牌字「MAPOROO」月搜量
   - 訂單數、客單價、新舊客比、轉換率
3. 資料源沒接通的欄位，**照實寫「待接入」並列出老闆需要提供什麼**——不要推估、不要編數字
4. 交出「基準線報告 + 待補資料清單」給雅琪，這就是第一週的交付

## 選題 SOP（每週產出 3 個新選題）

> [!IMPORTANT]
> **2026-08-05 起，選題不再綁產品線。**
> 部落格是純知識世界，零商品置入（見 `knowledge/maporoo-brand-dna.md` 第三節）。
> 所以選題的唯一標準是**「有沒有人在搜、我們有沒有機會排前面」**，
> 不是「這個題目能不能帶到我們的商品」。
> 拿產品關聯度去篩選題，只會逼出偽裝的推薦文。

1. **找困擾字與好奇字**：從關鍵字工具撈「困擾型搜尋」與「這是什麼型搜尋」，月搜量 500 以上優先
2. **對照四個內容型態**（02 部門的產線就是這四種）：

   | 型態 | 選題長相 | 關鍵字特徵 |
   | :-- | :-- | :-- |
   | **A 日常保健** | 每天吃八顆蛋會怎樣、掉髮跟營養有關嗎、睡不好身體先出什麼問題 | 「怎麼吃」「有效嗎」「會怎樣」 |
   | **B 名人／醫師經驗** | 某藝人分享的健康經驗、醫師在節目上講的觀念 | 人名 ＋ 症狀、話題性事件 |
   | **C 醫美趨勢科普** | PDRN 為什麼這麼夯、某療程最近為什麼紅 | 成分名、療程名、「是什麼」「原理」 |
   | **D 生活推薦** | 哪裡好玩、哪裡好吃 | ⚠ 待老闆確認是否啟動 |

3. **評估贏面**：SERP 前 10 若被醫美診所、內容農場佔據，我們的知識深度與可信度有沒有機會擠進前 3？
4. **算長尾**：好選題一篇能吃 50 個以上關鍵字
5. **趨勢字是我們的主場**：PDRN、外泌體這類成分正在紅，搜的人多但寫得清楚的少。
   我們寫「它是什麼、為什麼診所在用、一般人該知道什麼」——**寫到這裡為止，不往下寫成推薦**
6. **話題字要快**：名人健康話題的搜尋量是脈衝式的，發生後 48 小時內出稿才吃得到
7. 輸出「選題卡」給 02 內容編輯部：目標主字、周邊長尾字、搜尋意圖、**內容型態（A/B/C/D）**、可查證的出處線索、參考競品文
   - **選題卡不再有「建議內鏈產品」欄位**——這個欄位取消了

## 找橋 SOP（每月一次）

知識文不直接賣東西，所以要另外盯兩座橋有沒有在通：

| 橋 | 要看的數字 | 給誰 |
| :-- | :-- | :-- |
| 再行銷受眾池 | 文章頁的受眾累積量、再行銷廣告的 ROAS | 06 |
| 品牌字回搜 | 「MAPOROO」月搜量、直接流量 | 08 |

（電子報訂閱已於 2026-08-05 取消，不再是橋。）

兩座橋都不通，代表流量在漏——這時才是重新檢討內容策略的時機，**不是回頭去置入商品**。
另外提醒：兩座橋都是慢的，前幾個月看不到業績回報是預期內的，不要因此判定內容策略失敗。

## 週報 SOP

依 `knowledge/kpi-dashboard.md` 的週報格式，每週一交給雅琪。
週報第一行永遠先講兩個數字的環比（基準線建立前，先講絕對值與資料源狀態）。

## 鐵律

- **不虛構數據**。沒有的數字寫「待接入」，推估值一律標記「推估」與推估方法
- 任何選題卡都要說得出「這篇文章的讀者，最後會走到哪一個產品頁」
