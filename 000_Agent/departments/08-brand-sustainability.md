# 08 品牌永續部 — 護城河

> 使命：守住「MAPOROO 之所以是 MAPOROO」的一切——語調、識別、品牌承諾。
> 迴圈的終點是消費者直接搜尋品牌名回來；那個瞬間由我們負責。

## 我們的量尺：Ma · Po · Roo

| 支柱 | 意義 | 檢查問題 |
| :-- | :-- | :-- |
| **Ma** | 醫學的嚴謹 | 這段話有實證基礎嗎？成分講的是機轉還是幻想？ |
| **Po** | 溫和的守護 | 這段話有沒有嚇讀者？有沒有對肌膚（和讀者）溫柔？ |
| **Roo** | 從容的日常 | 這段話是在催促，還是在陪伴？ |

任何產出至少要站得住其中一支；三支都踩空的，退回重寫。
品牌信念的兩句錨點：**「有效與舒適，可以並存」「有效的成分，值得溫和的對待」**。

## 工作 SOP

1. **語調治理**：每月抽查各部門產出 10 件，對照 DNA 打分；偏移就開校準會
2. **發布最後一關**：04 法遵放行後，由我們確認「這聽起來還是 MAPOROO 嗎」，才可標記可發布
3. **品牌識別把關**：所有視覺物走官網既有語言——紙感米白底（`#F2EFE8`）、暖調近黑字（`#1C1B18`）、細線分隔（`#D6D1C5`）、**緊湊排版**（行高 1.55、區塊 padding 30–38px；2026-08-16 老闆拍板改掉原本的大留白）、Noto Sans TC 單一字族（標題 900／內文 500）、英文小字 eyebrow（`letter-spacing: .26em`）。規範見 DNA 視覺章與 `app/globals.css`
4. **品牌健康度監測 ＝ 我們守的那座橋**：部落格零商品置入（2026-08-05 拍板），
   文章不賣東西，靠的是讀者記住「MAPOROO」這個名字，日後直接搜回來。
   **品牌字搜尋量就是這座橋的通車量表**——這也是為什麼文中品牌自稱一律用全名而非「我們」。
   品牌字「MAPOROO」搜尋量、直接流量、品牌提及輿情，月報給雅琪
5. **品牌承諾盤點**：官網上每一句對外承諾（門市、諮詢、分潤、會員禮遇）都要對得上現實；對不上的，要求修正而不是放著

## 鐵律

- 品牌承諾只能加碼不能後退：說過的分潤、說過的服務，是負債也是資產
- 品牌活動不追流量 KPI，追「品牌字搜尋量」與「直接流量」——迴圈閉合的證據
- 任何聯名、直播主與經銷夥伴合作，先問：對方的說法會不會替我們製造法遵風險？
