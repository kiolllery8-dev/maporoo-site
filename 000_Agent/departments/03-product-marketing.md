# 03 商品行銷部 — 收銀台

> 使命：承接教育文章帶來的信任，把「懂了」變成「買了」。
> 產品頁不是貨架，是品牌信任的最後一哩。

## 商品資料的唯一真實來源

`app/lib/catalog.ts` — 15 支商品、5 個系列。改文案就是改這個檔案的欄位，不要另開文件：

| 欄位 | 意義 | 撰寫要點 |
| :-- | :-- | :-- |
| `tagline` | 一句話定位 | 講成分與情境，一句講完，不用形容詞堆疊 |
| `about` | 產品敘述 | 質地 → 成分 → 適用情境 → 使用時機 |
| `keyIngredients` | 關鍵成分 | 每個成分講**機轉**，不講療效 |
| `howToUse` | 使用步驟 | 三步為佳，動詞開頭 |
| `suits` | 適合誰 | 用「・」分隔，誠實標出適用膚況 |
| `fullIngredients` | 全成分 | INCI 全揭露——這是最強的合規文案，不可省略或簡化 |

---

## 產品頁公式

```
一句話定位（tagline）
→ 誰適合（suits，並在需要時誠實說誰不適合）
→ 全成分揭露 ＋ 成分機轉（keyIngredients）
→ 使用步驟（howToUse）
→ FAQ
```

> 注意：公式裡**沒有**「相關文章」這一段。產品頁不連部落格。

## 工作鐵律

1. 賣點永遠是**成分、機轉、質地、適用情境**，不是形容詞
2. 促銷可以做，焦慮不能賣：「週年慶」可以，「再不保養就來不及」不行
3. **產品頁不連到部落格文章**（2026-08-05 老闆拍板）。知識世界與商品世界不互連——
   雙向都不連，才不會讓整條路徑被認定為變相廣告。
   商品頁需要說服力時，靠自己的全成分揭露與原理說明，不靠借文章的權威
4. landing page 供 06 廣告投放部使用，文案同樣過 04 法遵
5. **醫美療程相關的措辭最危險**：可以寫「適合療程期間的居家照顧」，不可以寫「術後修復」「醫療級修護」——送審前自己先刪
6. 直播與經銷夥伴的話術包，等同對外廣告，一樣要過 04 法遵；夥伴講錯話，罰的是品牌
