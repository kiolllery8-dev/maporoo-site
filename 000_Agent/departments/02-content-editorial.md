## 我們寫什麼（四個內容型態）

### 型態 A：日常保健知識

聚焦「怎麼吃」「吃了身體會有什麼改變」「生活習慣與身體的關係」。

範例主題：
- 每天吃八顆蛋會怎樣？營養師怎麼看
- 掉髮跟營養不良有關嗎？
- 睡眠不足的時候，身體先出問題的是哪裡

### 型態 B：名人／醫師經驗轉述

有話題性、有知識性、容易被模仿學習的真實案例。

**標準範例（老闆指定的參考樣本）**：
> 藍心湄曾在節目上分享自己有掉髮問題，即便平時飲食控制得宜，檢查後才發現是營養不良，
> 醫師建議她每天吃八顆蛋。

寫法：轉述事件 → 解釋背後的原理 → 給讀者可參考的觀念 → 標明「這是個人經驗，不是醫療建議」。

### 型態 C：醫美趨勢科普

只講**現象與原理**，不講我們有賣。

**標準範例（老闆指定的參考樣本）**：
> 「PDRN 最近為什麼這麼夯？」→ 因為很多醫美診所在使用，所以熱度起來了。
> 接著解釋它是什麼、為什麼診所會用、一般人該知道什麼。

**寫到「這是什麼成分」為止，不要往下寫成「所以你該買含它的保養品」。**

### 型態 D：生活推薦

哪裡好玩、哪裡好吃——與品牌氣質相符的生活內容。
⚠ 待老闆確認是否啟動、由誰供稿（`maporoo-brand-dna.md` 第五節第 8 題）。

## 第 0 號任務：官網目前沒有部落格

首頁「閱讀 ─ LIBRARY」區塊的六篇文章是 `app/lib/catalog.ts` 的 `reads` 假資料，**沒有對應路由、點不進去**。
在寫第一篇文章之前，先交出**內容架構規格**給雅琪與工程端：

1. 路由設計（建議 `/read` 列表與 `/read/[slug]` 內文）
2. 文章資料結構（slug / 分類 / 標題 / meta description / 封面 / 閱讀時間 / 正文 / 出處 / 延伸閱讀）
   - **注意：資料結構裡不要有 `relatedProducts` 欄位**——沒有這個欄位，就沒人會偷偷置入
3. 分類要換掉：官網現有的「成分學／保養指南／生活文化／設計」偏商品導向，
   建議改為 **日常保健／趨勢觀察／生活風格**（待雅琪與老闆確認）
4. SEO 必要件：canonical、OG、JSON-LD（Article）、sitemap 收錄
5. 文末只放**延伸閱讀（其他文章）**，不放商品區塊、不放訂閱表單

路由上線前，文章一律寫成 Markdown 存 `000_Agent/output/articles/`。

## 寫作鐵律

1. **零商品置入**（見最高鐵律）
2. 語調走**專業顧問感**：先給結論 → 再給原理 → 附上邊界（`maporoo-brand-dna.md` 2.1）
3. 人稱一律 **「你」**；需要提到品牌時用 **「MAPOROO」**，不用「我們」
4. 術語**一律淺**：不出現英文學名、分子量、濃度、文獻引用。淺的是用詞，不是思考——原理還是要講對
5. 標題用**問句公式**（疑問句 ＋ 破除迷思 ＋ 數字化建議）——搜尋文的流量靠這個
6. 引用名人或醫師說法，**必須標明出處**（節目名稱、日期、報導連結），並附「個人經驗／非醫療建議」聲明
7. 涉及症狀或飲食建議，必含「這幾種情況請諮詢醫師或營養師」段落
8. 一篇打一個主字＋一整片長尾（H2/H3 涵蓋周邊問法）
9. 文末**只有延伸閱讀（其他文章）**。不放商品、不放訂閱、不放任何表單——電子報訂閱已於 2026-08-05 取消
