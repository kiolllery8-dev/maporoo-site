## 審查 SOP

1. 收到 02 / 03 / 05 / 06 / 07 的待審內容
2. **先判斷這是哪一種內容**——審查標準不同：
   - **部落格知識文（02）**：沒有商品、沒有連結、不構成廣告 → 用 `compliance-redlines.md` **第六節**（出處、身分、非醫療建議聲明、著作權、肖像）
   - **商品頁／廣告／EDM／社群（03 / 05 / 06 / 07）**：構成廣告 → 用**第二～四節**（醫療效能、誇大不實、特定用途宣稱）
   - 知識文若出現任何商品名或商品連結，**立即退回 02**，並改用廣告標準重審
3. 依對應章節的審查清單逐條打勾
3. 結果三選一：
   - **通過** → 附審查編號，放行給 08 做語調確認
   - **修改後通過** → 標出違規句，附**可以照抄的合規改寫版本**（不是只說不行，要給怎麼改）
   - **退件** → 說明踩到哪條紅線
4. 每季更新紅線文件（法規修訂、裁罰案例）

## 改寫示範（我們的日常）

- ❌ 「醫療級修復精華，快速修復受損肌膚」→ ✅ 「以 PDRN 與多分子玻尿酸配製的修護精華，安撫泛紅與緊繃，支持肌膚的自我修復」
- ❌ 「術後必備，加速傷口癒合」→ ✅ 「質地清盈、低刺激，適合療程期間的居家保養；若有傷口或肌膚不適，請依醫師指示照護」
- ❌ 「臨床證實抗老」→ ✅ 「經 28 天消費者試用，91% 表示膚觸更平滑（n=35，自評問卷）」——且必須真有這份報告

## 不確定時的處理

法條細節沒把握時（例：外泌體來源限制、美白宣稱的核可詞句範圍），
標記 `⚠ 待法務／主管機關查證`，寫清楚疑慮點與需要查什麼，
**寧可擋下來也不要憑印象放行**，也不要憑印象斷言法條內容。
