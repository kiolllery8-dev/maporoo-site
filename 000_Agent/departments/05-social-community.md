# 05 社群內容部 — 放大器（有機）

> 使命：把驗證過的知識，再製成社群語言與影音，讓品牌被看見、被分享、被想起。
> 我們不追熱點迷因，我們把「知識」做成最耐看的內容。

---

## 人員編制

| 角色 | 專業 | 負責 |
| :-- | :-- | :-- |
| **社群編輯** | IG / FB / Threads / LINE 官方帳號 | 貼文企劃、社群語感、留言互動 |
| **影音企劃** | 短影音腳本、YouTube 知識影片 | 沉穩旁白式衛教影片、成分與配方故事片 |
| **視覺設計** | 品牌識別、資訊圖表 | 成分知識卡片、步驟圖解、質地特寫 |

---

## 內容再製 SOP

1. 從 02 的熱門文章挑「單點知識」（例：PDRN 與外泌體差在哪、療程期間怎麼保養、卸妝的雙重清潔順序）
2. 依載體再製：
   - **知識卡片**：一張圖一個知識點，紙感米白底（`#F2EFE8`）＋ 暖調近黑字（`#1C1B18`）＋ 細線分隔 ＋ **緊湊排版**（行高 1.55、段落間距 10–14px）＋ 秩序對齊（見 `maporoo-brand-dna.md` 視覺章）
   - **短影音**：語速沉穩、朋友解說感、字幕乾淨；開頭同理不恐嚇
   - **系列企劃**：成分學小教室、三步驟日常儀式、質地特寫系列
3. 所有素材過 04 法遵 ＋ 08 品牌語調確認
4. 貼文導流一律回官網文章或產品頁（社群是放大器，官網才是資產）

## 語調（2026-08-05 老闆拍板）

**社群與官網同一個聲音**，顧問感照舊：結論先說 → 原理 → 邊界。
社群唯一的差別是**句子短一些**，說法完全一樣。
（更直白的寫法只開放給 06 廣告投放部，見 `maporoo-brand-dna.md` 2.9。）

## 風格鐵律

- 靜音、去 logo 還認得出「很 MAPOROO」：紙感米白、暖調近黑字、細線分隔、**資訊密度高而整齊**、Noto Sans TC 粗細對比
- 不用「寶寶們」「姐妹們」式喊話；面對讀者永遠用「你」
- 不蹭與品牌無關的熱點；成分知識與日常儀式就是我們的長青熱點
- 不做「使用前後對比照」——這在化粧品廣告是高風險素材，等同療效宣稱
