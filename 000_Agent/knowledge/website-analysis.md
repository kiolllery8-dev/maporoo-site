### 選題的三個規律（策略數據部必背）

1. **搜的是「症狀」，不是「產品」**：消費者搜「頭皮長痘痘」而不是「洗髮精推薦」——在對方還沒想到要買東西時就出現，獲客成本趨近於零
2. **主題緊貼產品線**：每個內容集群背後都站著一條產品線
3. **長尾包抄**：一篇文章平均吃下 50–130 個關鍵字——寫一篇，收一整個語意場

## 三、銷售迴圈全圖（機器的運轉方式）

```
【獲客】症狀搜尋 → Google 前三名
【教育】衛教文章：成因 → 迷思 → 幾種情況要就醫 → 保養 N 招
   ↓ 文內自然置入 + 文末相關商品　←　⚠ 這一步 MAPOROO 不做（零置入，見第五節）
【信任】產品頁：全成分揭露、成分機轉、來源故事
   ↓ 首購
【放大】社群再製知識卡片 ＋ 精準付費投放（驗證過的內容才投）
   ↓
【回購】EDM / LINE 持續教育 → 回購與推薦
   ↓
【回饋】流量與營收數據 → 下一輪選題與資源分配
```

三個設計精髓：

1. **教育內容同時是法遵策略**：談症狀與保養觀念、提醒就醫，不宣稱產品療效——既贏得搜尋排名與信任，也天然避開化粧品廣告的法規地雷
2. **內容是資產不是費用**：文章排上前三名後持續產生免費流量，複利累積；廣告只用來放大已驗證的內容
3. **品牌字是迴圈的出口指標**：教育做得夠久，消費者會直接搜品牌回來，這就是迴圈閉合的證據

### 5.5 第一階段建議（給雅琪排優先序）

1. **01** 建立基準線 → 沒有數字之前不做環比判讀
2. **04** 清掉第 5.4 表第 6 項的法遵風險 → 這是止血，不是成長
3. **02 ＋ 工程** 開出 `/read` 與 `/read/[slug]` 路由 → 把獲客環節接上
   - 資料結構**不要有 `relatedProducts` 欄位**；沒有欄位，就沒人會偷偷置入
4. ~~接通電子報~~ **已取消**（2026-08-05 老闆決定不做訂閱）。
   橋從三座變兩座，**06 的再行銷受眾池因此成為唯一可以用錢加速的路徑**——
   這讓第 6 項（文章頁裝像素）的優先度往上跳（人稱定案 2.2）
5. **01 → 02** 第一批選題：優先打**趨勢科普字**（PDRN 為什麼這麼夯、外泌體是什麼），
   搜的人多、寫得清楚的少，而且天然合規——寫到「這是什麼」為止，不往下推薦商品
6. **06** 文章頁裝上再行銷像素 → 讀過文章的人才能進受眾池
7. **03** 產品頁補上 FAQ（**不補文章內鏈**，兩個世界不互連）
