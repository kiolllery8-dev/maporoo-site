## 一、品牌世界觀（我們為什麼這樣想）

MAPOROO 的所有語言都從一個核心信念長出來：

> **有效與舒適，可以並存。**
> **有效的成分，值得溫和的對待。**

由此展開的思想結構：

1. **不二選一**：市場預設「有效就會刺激、溫和就沒效果」。MAPOROO 的全部主張就是拒絕這個二選一。
2. **理解先於購買**：我們相信消費者懂了才會買，也才會留下——所以知識是我們給出去的東西，不是換購買的籌碼。
3. **從膚況出發，不從貨架出發**：導購入口是「依肌膚困擾／依膚質／依成分」，不是「熱銷排行」。
4. **從容**：保養是日常，不是軍備競賽。我們不催促、不製造匱乏感。

### 三支柱：Ma · Po · Roo

| 支柱 | 一句話 | 展開 |
| :-- | :-- | :-- |
| **Ma** | 醫學的嚴謹 | 以實證為基礎，選擇真正有效的成分 |
| **Po** | 溫和的守護 | 有效之餘，也對肌膚溫柔以待 |
| **Roo** | 從容的日常 | 讓保養，回到一種安靜的日常儀式 |

## 二、語言指紋（老闆拍板版）

### 2.1 大方向：專業顧問感

MAPOROO 說話像一個**把話講得很白的專業顧問**——不是朋友閒聊，也不是冷冰冰的規格表。

固定的說話順序：

```
先給結論 → 再給依據（原理） → 附上邊界（誰不適合、什麼情況該問醫師）
```

範例（教育文開頭）：

> 結論先說：療程期間的保養，做減法就好。以下是三個原則。

### 2.2 人稱：你 ＋ MAPOROO

- 對讀者一律用 **「你」**，不用「您」、不用「大家」、不用「寶寶們／姐妹們」
- 品牌自稱一律用 **「MAPOROO」**，不用「我們」當主詞
  - ✅ 「MAPOROO 選擇 PDRN，因為它與人體 DNA 相似。」
  - ✅ 「MAPOROO 的建議是：先做減法。」
  - ❌ 「我們選擇 PDRN⋯」
- 附帶好處：品牌字曝光提高，對品牌搜尋量有利

> 例外：`000_Agent` 內部文件與部門之間的溝通不受此限。

### 2.3 術語深度：一律淺（懂就好）

**不出現**英文學名、分子量、濃度、受體路徑、文獻引用。用比喻與情境把原理講清楚。

- ✅ 「PDRN 是一種跟肌膚很相像的修護成分。它安撫泛紅，支持肌膚自己修復。」
- ❌ 「PDRN（Polydeoxyribonucleotide），分子量約 50–1,500 kDa，作用路徑與 A2A 受體相關。」

> [!IMPORTANT]
> **淺 ≠ 隨便。**
> 顧問感的嚴謹**靠結構撐，不靠術語撐**——結論先說、原理講對、邊界講明。
> 寫手不准因為「要寫得淺」就省略原理或跳過邊界句。淺的是用詞，不是思考。

### 2.4 情緒溫度：分線

| 線別 | 系列 | 語調 |
| :-- | :-- | :-- |
| **功效線** | 修復 RESTORE、亮白 CLARITY、保濕 HYDRATION、頭皮 SCALP | **理性**。講原理、講適用、講順序。感性句最多收尾一句 |
| **感性線** | 香氛 AROMATICS（香水、沐浴露、護髮油） | **感性**。可以寫畫面、寫時間、寫感受 |

功效線範例：

> 肌膚疲憊的時候，保養做少一點就好。PDRN 安撫泛紅與緊繃，支持肌膚自己修復。

感性線範例：

> 佛手柑開場，像清晨推開窗的那一瞬。線條往中間走，綠意草本接住，最後落在白木質的溫度上。

**分線不是分裂**：兩條線共用同一套人稱、同一套禁詞、同一套邊界紀律。差別只在能不能寫畫面。

### 2.5 標題公式：混用

| 內容型態 | 公式 | 範例 |
| :-- | :-- | :-- |
| **搜尋文**（要流量） | 疑問句 ＋ 破除迷思 ＋ 數字化建議 | 「PDRN 最近為什麼這麼夯？醫美診所在用的原因、3 件你該先知道的事」 |
| **品牌文／香氛文**（要質感） | 斷言句 | 「有效的成分，值得溫和的對待」 |

理由：兩者不必二選一——搜尋文負責流量，品牌文負責調性。

### 2.6 句子的形狀

- 短句、句號結尾、幾乎不用驚嘆號
- 使用步驟一律三步、動詞開頭
- 中英雙軌版面：中文標題 ＋ 全大寫英文 eyebrow（`COLLECTIONS`、`LIBRARY`）
- 一律繁體中文與台灣用語（影片不是視頻、訊息不是信息、品質不是質量）
- 標點全形；中英夾寫前後留空格；數字半形，範圍用 en dash（`2–3 滴`、`30ml`、`NT$ 1,680`）

### 2.7 詞彙表

| 常用（多用） | 迴避（不用） |
| :-- | :-- |
| 安撫、支持、回復、鎖水、平衡、調理、舒緩 | 修復受損細胞、促進癒合、消炎、殺菌 |
| 溫和、清盈、服貼、綿潤、柔軟、不緊繃 | 逆天、秒殺、爆款、吹彈可破 |
| 從容、安定、日常 | 再不保養就來不及、拯救、急救 |
| 實證、原理、全成分、可信、選擇 | 獨家祕方、神級、頂級、醫療級 |
| 有助於、可留意、建議、適合 | 保證、根治、一次見效、永久 |
| 肌膚、頭皮、髮絲（部位講精確） | 疾病名 ＋ 改善 |
| 你 ／ MAPOROO | 您 ／ 我們（當主詞）／ 寶寶們 |

### 老闆的個人禁詞（2026-08-05 拍板，出現即退稿）

| 禁詞 | 為什麼 |
| :-- | :-- |
| **激推** | 網紅推薦文的語氣，與顧問感衝突 |
| **必收** | 同上，且暗示匱乏感 |
| **對自己好一點** | 情緒勒索式文案 |
| **你值得** | 同上 |
| **犒賞自己** | 同上 |
| **儀式感** | 同上——被用爛的行銷詞 |
| **節奏** | 保養文案的萬用填充詞，講了等於沒講 |

這七個字詞**任何載體都不准出現**：文章、商品頁、社群、EDM、廣告、影音字幕皆同。

> 「節奏」的替代寫法：直接講做法或講機轉。
> 「支持肌膚自我修復的節奏」→ 「支持肌膚的自我修復」。
> 內部文件講排程時的「週節奏、回購節奏、檔期節奏」不在此限。

> **老闆沒有禁、但仍受其他規則限制的詞**：
> - 無雷、CP 值、閉眼買——老闆沒點名，但與顧問感不合，寫手請自行判斷；除非有理由，預設不用
> - 術後、療程後、水光、少女針、醫美級保養——**老闆沒有個人禁用**，
>   但「醫美級保養」等身分誤導用語仍被法規紅線擋住（第二節）。
>   在**商品頁與廣告**一律不得使用；在**部落格趨勢科普文**中，
>   作為描述診所現況的中性用語（例：「很多人做完療程後會問⋯」）是可以的。

> [!CAUTION]
> **⚠「日常儀式」待老闆裁示。**
> 老闆禁的是「儀式感」。但官網 `pillars` 的 Roo 支柱寫著
> 「讓保養，回到一種安靜的**日常儀式**」，本文件第一節也沿用了這個說法。
> 兩者相鄰但不同。**在老闆裁示前，「日常儀式」暫時保留**（它是既有品牌資產，不是行銷贅詞），
> 但不得再衍生出「儀式感」「保養儀式感」等變形。

### 2.8 AI 腔清單（2026-08-05 老闆拍板）

寫給人看的東西，要像人寫的。以下六種句型出現在對外文案裡即退稿。

| # | 句型 | 壞例 | 改成 |
| :-- | :-- | :-- | :-- |
| 1 | **否定對比句**（最嚴重） | 「重點不是加強，而是減法」 | 「重點是減法」 |
| 2 | **用否定解釋做法** | 「別急著加強保養，因為加強不會讓屏障變好」 | 「先把步驟減到三步」 |
| 3 | **因為⋯所以⋯推理鏈** | 「因為屏障正在重建，所以這時候要溫和」 | 「屏障正在重建，這時候溫和一點」 |
| 4 | **「你可以⋯」建議句** | 「你可以試著減少步驟」 | 「把步驟減到三步」 |
| 5 | **「這樣」收尾** | 「保持清潔就好，這樣屏障才會穩定」 | 「保持清潔，屏障會慢慢穩下來」 |
| 6 | **倒推句**（先講反面再繞回正面） | 「我不會這樣做，因為這樣做沒有效果，所以應該那樣做」 | 「這樣做就好」 |

**核心一句話**：**直接說怎麼做，說它是什麼。**

寫完檢查兩件事：

1. 全文搜「不是」「而是」「因為」「所以」「這樣」「你可以」——出現就重寫那一句
2. 念出聲。像人在講話，過；像簡報摘要，重寫

> **適用範圍**：對外文案（文章、商品頁、社群、EDM、廣告、影音字幕）。
> `000_Agent/` 底下的內部規則文件、SOP、法遵清單**不受此限**——
> 那些文件要靠「不得、禁止、退稿」才能運作。

### 2.9 通路語調（2026-08-05 老闆拍板）

**官網與社群同一個聲音；廣告可以更直白。**

| 通路 | 語調 |
| :-- | :-- |
| 官網（首頁、商品頁、部落格） | 顧問感，完整版。結論先說 → 原理 → 邊界 |
| IG / FB / Threads / LINE | **與官網相同**。一則一知識點，句子短一些，說法一樣 |
| 廣告（Google / Meta / LINE） | **更直白**。三秒內講完一件事 |

「更直白」的定義，寫死在這裡，避免被無限上綱：

**廣告可以放寬的**

- 句子更短，一句一個重點
- 開頭直接切入讀者的處境，省略鋪陳
- 標題可以只有半句
- 可以只講一個成分、一個情境，其餘留在落地頁

**廣告不准放寬的**

- 宣稱的尺度：廣告的裁罰比內文更重，法規紅線在廣告只會更緊
- 七個禁詞
- AI 腔六種句型
- 人稱：對讀者「你」、品牌自稱「MAPOROO」
- 販賣焦慮

一句話：**廣告放寬的是句子的長度，宣稱的尺度一格都不放。**

範例：

| 通路 | 同一件事的寫法 |
| :-- | :-- |
| 官網商品頁 | 「質地清盈、迅速被肌膚吸收的修護精華。以 PDRN 搭配多分子玻尿酸，層層滲透、安撫泛紅與緊繃，支持肌膚的自我修復。」 |
| 社群貼文 | 「PDRN 是一種跟肌膚很相像的修護成分。它安撫泛紅，支持肌膚自己修復。」 |
| 廣告 | 「泛紅的日子，保養做少一點。PDRN 修復精華液。」 |

### 2.10 醫美定位怎麼講（2026-08-05 老闆拍板）

醫美是 MAPOROO 的定位，也是最容易踩線的地方。講法固定成兩句話，兩句都繞開「等級」。

| 講什麼 | 怎麼講 | 範例 |
| :-- | :-- | :-- |
| **成分** | 講它被用在哪裡（來源場景） | 「PDRN，醫美診所在用的修護成分」 |
| **商品** | 講什麼時候用得上（使用情境） | 「適合各種膚況，療程期間也能用」 |

**一律不碰的**：醫療級、醫美級、療程級、藥用、處方級、院線級——任何把 MAPOROO 說成某種「等級」的寫法。
理由：等級寫法讓消費者誤認產品具醫療屬性，屬法規紅線（見 `compliance-redlines.md` 第二節「身分誤導類」）。
來源場景與使用情境屬事實陳述，風險低得多，辨識度也夠。

**官網首頁的定版寫法**（2026-08-05 改，`app/page.tsx` COLLECTIONS 段）：

> MAPOROO 選的成分，來自醫美診所在用的那一類——PDRN、外泌體、胜肽與玻尿酸。適合各種膚況，療程期間也能用。

改動內容：拿掉「醫美，是我們對功效的標準」的等級框架、拿掉「美白」（屬特定用途化粧品宣稱，狀態待查證）、
「我們」改成「MAPOROO」。

> [!NOTE]
> 這句仍需 04 法遵審查部正式簽核。文案寫法已依規則調整，形式審查尚未完成。

**部落格的醫美趨勢文**（型態 C）用同一套邏輯：講現象與原理，寫到「診所為什麼在用」為止。
往下寫成「所以你該買含這個成分的產品」的那一刻，整篇文章從知識文變成廣告，紅線全部適用。

## 三、內容分流原則（老闆 2026-08-05 拍板，最高優先）

> 這一節推翻了原版系統「文內置入商品連結」的做法。**以此節為準。**

MAPOROO 的內容分成兩個世界，**中間不架橋**：

| | 部落格／知識內容 | 商品頁／官網轉換頁 |
| :-- | :-- | :-- |
| 目的 | 知識分享、把人帶進站、養品牌曝光 | 賣東西 |
| 商品名 | **絕對不出現** | 當然出現 |
| 商品連結 | **絕對不放** | — |
| 商品相關字眼 | **絕對不帶**（不寫「保養品怎麼挑」「精華液推薦」這種擦邊題） | — |
| 語氣 | 專業顧問，純分享 | 專業顧問，該賣就賣 |

### 3.1 部落格能寫什麼

1. **日常保健知識**：怎麼吃、吃了身體會有什麼改變、生活作息與身體的關係
2. **名人／醫師的經驗分享轉述**
   - 範例：藍心湄在節目上分享掉髮困擾，飲食控制良好卻仍掉髮，檢查後發現是營養不良，醫師建議每天吃八顆蛋
   - 這類內容有知識性、有話題性、容易被模仿與轉傳——這就是我們要的流量
3. **醫美趨勢科普**：為什麼某個成分或療程最近很紅
   - 範例：「PDRN 最近為什麼這麼夯？——因為很多醫美診所在用，所以熱度起來了」
   - **只講現象與原理，不講我們有賣**
4. **生活推薦**：哪裡好玩、哪裡好吃——與品牌氣質相符的生活內容

### 3.2 部落格絕對不能做的事

- ❌ 提到任何 MAPOROO 商品名稱
- ❌ 連到 `/products/*` 任何頁面
- ❌ 文末「相關商品」區塊
- ❌ 「想找 XX 的話可以留意成分表⋯」這種擦邊置入
- ❌ 把文章寫成偽裝的推薦文

### 3.3 那流量怎麼變業績？

不靠內鏈，也不靠收 email（**電子報訂閱已於 2026-08-05 取消**），只剩兩座橋：

| 橋樑 | 機制 | 負責部門 |
| :-- | :-- | :-- |
| **再行銷受眾池** | 讀過文章的人進入廣告受眾，用商品頁廣告承接 | 06 |
| **品牌字回搜** | 讀者記得 MAPOROO 這個名字，日後直接搜品牌進站——迴圈閉合的證據 | 08 ＋ 01 |

> [!WARNING]
> **只剩兩座橋，兩座都不快。**
> 再行銷要有廣告預算與像素才會動；品牌字要養很久才長得出來。
> 這代表部落格在相當長一段時間內**看不到直接業績回報**——
> 這是策略的已知代價，不是執行失敗。任何人想用「沒有轉換」當理由要求置入商品，
> 請他先看這一節。

**KPI 換算**：部落格的 KPI 是**流量與品牌字成長**，不是轉換率。
不要拿轉換率去評判一篇知識文，那會逼寫手偷偷置入。

### 3.4 商品頁的置入原則（這裡才賣東西）

1. 賣點是**成分、原理、質地、適用情境**，不是形容詞
2. 全成分（INCI）揭露是標配，不得省略
3. 涉及症狀時附「這幾種情況請諮詢醫師」
4. 產品頁**不反向連到部落格文章**——兩個世界不互連，避免整條路徑被認定為變相廣告
