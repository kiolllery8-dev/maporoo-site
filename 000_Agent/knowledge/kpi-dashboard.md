---

## 北極星：兩個數字

| 數字 | 組成 | 資料來源 | 目標 |
| :-- | :-- | :-- | :-- |
| **業績** | 官網營收 ＝ 訂單數 × 客單價（拆新客／舊客） | 電商後台 / GA4 電子商務 | 週環比 ≥ +2% |

## 判讀規則（雅琪的裁決邏輯）

| 情境 | 雅琪動作 |
| :-- | :-- |
| 兩個數字都漲 | 加碼當週最有效的動作；把成功選題記進 `memory/MEMORY.md` |
| 流量漲、業績沒漲 | 轉換環節漏水 → 派 03 商品行銷部查產品頁與動線、07 查回購 |
| 業績漲、流量沒漲 | 靠促銷或舊客撐 → 派 02 內容編輯部補新選題，避免吃老本 |
| 兩個都跌，連續兩週 | 跑 `workflows/weekly-growth-loop.md` 全員會議，重新分配資源 |
| 基準線尚未建立 | 不做判讀。派 01 完成第 0 號任務，本週唯一交付就是基準線報告 |

## 部門 KPI → 兩個數字的折算表

| 部門 | 部門 KPI | 折算到北極星 |
| :-- | :-- | :-- |
| 01 策略數據 | 選題命中率（上線 8 週內進前 10 的比例） | 流量 |
| 02 內容編輯 | 自然流量、關鍵字前三名數量 | 流量 |
| 03 商品行銷 | 轉換率、客單價 | 業績 |
| 04 法遵審查 | 違規事件數（目標 0）、審查時效 | 保護業績（罰款與下架＝負業績） |
| 05 社群內容 | 互動率、社群導流 session 數 | 流量 |
| 06 廣告投放 | ROAS、CPA | 業績＋流量 |
| 07 會員經營 | 回購率、EDM/LINE 轉換、LTV | 業績 |
| 08 品牌永續 | 品牌字搜尋量、直接流量 | 流量（迴圈閉合指標） |
