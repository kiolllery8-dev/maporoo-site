# 法規紅線與合規寫法（MAPOROO 版）

> 給所有產出內容的部門：這不是「規避法令」，是**用教育取代宣稱**——
> 把法規限制變成信任優勢。
> 任何內容上線前，04 法遵審查部依這份文件審查。
>
> ⚠ **本文件是內部工作指引，不是法律意見**。條文細節與最新函釋以主管機關公告為準；
> 有疑慮的個案標記 `⚠ 待法務／主管機關查證`，不要憑印象斷言法條內容。

---

## 一、我們踩在哪些法規上

| 法規 | 管什麼 | 對我們的意義 |
| :-- | :-- | :-- |
| 化粧品衛生安全管理法 | 化粧品之標示、宣傳或廣告**不得有虛偽誇大或醫療效能** | MAPOROO 全品項的最高紅線（保養品、香水、沐浴、洗髮皆為化粧品） |
| 衛福部「化粧品標示宣傳廣告涉及虛偽誇大或醫療效能認定基準」 | 列出哪些詞句算醫療效能、哪些屬允許範圍 | 文案用詞白名單／黑名單的依據 |
| 特定用途化粧品（含美白、防曬等）相關規定 | 特定用途成分需符合核准並完成查驗登記／備查後方得宣稱 | **亮白系列的宣稱範圍取決於此** |
| 公平交易法 | 廣告不實、比較性廣告 | 「實證數據」必須真有實驗支持 |
| 藥事法／醫療器材相關規範 | 不得使消費者誤認為藥品或醫療器材 | 「醫療級」「醫美級」類用語的風險來源 |

MAPOROO **不販售食品**，所以食安法的廣告條文不直接適用。
但 2026-08-05 起部落格會寫「怎麼吃、吃了身體會怎樣」的保健內容——
**沒有販售就不是廣告，風險大幅下降，但仍不得對一般民眾提供醫療建議**。
這一類內容的專屬規則見第六節。
若未來推出口服美容產品，本文件需完整增補食品章節。

## 二、紅線詞（內容中出現即退件）

**醫療效能類**：治療、治癒、根治、根除、消炎、殺菌、抗敏（宣稱治療過敏）、
修復受損細胞、促進傷口癒合、術後修復、加速癒合、
以及**疾病名稱＋改善**的組合（濕疹、異位性皮膚炎、酒糟、脂漏性皮膚炎、毛囊炎⋯）。

**誇大保證類**：保證有效、一次見效、100% 有效、永久、逆轉老化、
醫師推薦（無真實授權）、臨床證實（無可提出的實驗報告）、
無效退費式的效果保證。

**身分誤導類**：醫療級、醫美級、療程級、藥用、處方級、院線級。
> 這一類最容易被忽略，因為聽起來像形容品質。但它讓消費者誤認產品具醫療屬性，是高風險用語。

**受限宣稱**：美白、除皺、防曬等屬特定用途化粧品範疇的宣稱，
僅能在核准範圍與已完成法定程序的前提下使用。無法確認狀態時，一律改用允許範圍的替代寫法。

## 三、合規寫法（把紅線變成信任）

### 1. 衛教歸衛教，產品歸產品

文章主體談**成因與生活對策**（衛教資訊，不是產品廣告）；
產品只出現在「保養建議」的其中一項，且只講**成分與使用情境**。

- ✅ 「清潔時可選擇質地溫和、成分單純的潔顏產品」
- ❌ 「使用本產品可改善毛囊炎」

### 2. 就醫提醒是標配，不是妥協

每篇涉及症狀的文章，必含「這幾種情況請就醫」段落。
這一段同時做到三件事：**守法（不越權談治療）、負責（讀者安全）、建立信任（我們不是什麼都要賣你）**。

- 範本句：「若出現紅腫熱痛、持續未改善或反覆發作，建議諮詢皮膚科醫師。」

### 3. 講機轉、給實證、附出處

- 成分功效講**機轉**：「玻尿酸有助於維持肌膚保水度」而非「玻尿酸讓你不再乾燥」
- 數據要**可舉證**：「實測 91% 使用者有感」必須真有消費者試用報告；寫明樣本數與條件
- 全成分（INCI）揭露本身就是最強的合規文案

### 4. 情緒上不販賣焦慮

法規管的是宣稱，品牌管的是態度：不用「再不保養就完了」式的恐嚇開頭。
用「你可能也遇過⋯其實這很常見」的同理開頭——這也是 MAPOROO 語調的一部分。

## 四、審查清單（04 法遵審查部逐條打勾）

- [ ] 全文無紅線詞（第二節黑名單，含「醫療級」類身分誤導用語）
- [ ] 產品置入段落只講成分、質地、使用情境，無療效因果句
- [ ] 涉及症狀 → 有「何時就醫」段落
- [ ] 引用數據 → 有可舉證的來源、樣本數與條件
- [ ] 標題無誇大保證（疑問句＋數字建議的公式天然安全）
- [ ] 美白／除皺類宣稱 → 已確認該品項的法定狀態，或已改寫為允許範圍
- [ ] 無使用前後對比照、無「療程效果」暗示圖
- [ ] 促銷內容價格與贈品資訊真實、有期限標示
- [ ] 對外合作素材（直播主話術包、經銷夥伴簡報）同樣通過本清單

## 六、部落格知識內容的專屬規則（2026-08-05 新增）

部落格改為**純知識、零商品置入**（見 `maporoo-brand-dna.md` 第三節）之後，
法遵的風險型態改變了——**廣告風險下降，但轉述風險上升**。

### 6.1 為什麼風險下降

文章沒有提到商品、沒有連到商品頁、沒有推薦購買，
就**不構成化粧品廣告**，第二節的醫療效能宣稱紅線大部分不適用。
這是這個策略的附帶好處，04 部門要認識到這一點，不要用審廣告的標準去卡知識文。

### 6.2 但這四件事還是會出事

| 風險 | 說明 | 處理 |
| :-- | :-- | :-- |
| **越權提供醫療建議** | 「掉髮就每天吃八顆蛋」寫成通則，等於對不特定人給醫療／營養處方 | 一律轉述為**個案經驗**，並附非醫療建議聲明 |
| **引用不實** | 名人根本沒說過、醫師身分造假、報導是農場文 | **查不到可信出處的說法不寫**；寫成「有此說法但無可查證來源」 |
| **著作權** | 大段複製報導或專欄內容 | 只摘重點、用自己的話寫；引用不超過必要範圍並註明出處 |
| **肖像與名譽** | 用名人照片、或把轉述寫成像該名人為品牌背書 | **不使用名人照片**；文中不得暗示任何人與 MAPOROO 有關係 |

### 6.3 必備的三個元件（型態 B、C 缺一即退件）

1. **出處**：節目／媒體名稱、時間、可查證的連結
2. **身分**：醫師姓名或所屬單位（查不到就不要寫「醫師說」，改寫「有醫療專業者指出」並說明來源限制）
3. **聲明**：文中必含——
   > 以上為個人經驗分享與知識整理，不是醫療建議。個別狀況請諮詢專業人員。

### 6.4 醫美趨勢文的邊界（型態 C）

可以寫：這個成分是什麼、為什麼診所在用、熱度從哪裡來、一般人該知道什麼。
**不可以寫**：所以你該去做這個療程、所以你該買含這個成分的產品、任何療效保證。
**尤其不可以**：寫完 PDRN 有多好，然後在文末以任何形式提到 MAPOROO 有賣——那會讓整篇文章從知識文變成廣告，第二節的紅線立刻全部適用。

### 6.5 審查清單（知識文專用）

- [ ] 全文無商品名、無 `/products/` 連結、無擦邊置入
- [ ] 名人／醫師說法有可查證出處，且身分表述正確
- [ ] 有非醫療建議聲明
- [ ] 飲食或保健建議寫成個案經驗，不是通則處方
- [ ] 涉及症狀 → 有「何時就醫／諮詢營養師」段落
- [ ] 未使用名人照片、未暗示任何人為品牌背書
- [ ] 引用他人文字在合理範圍內並註明出處
