# 標竿品牌語調 DNA（綠藤生機）— 方法參照教材

> 這是標竿品牌綠藤的語調拆解，當作**方法**參照。
> MAPOROO 自己的聲音以 `maporoo-brand-dna.md` 為最高依據——
> 我們學它的**結構與紀律**（標題公式、四段式安全結構、教育換信任的迴圈），
> 不抄它的**世界觀**（減法哲學、B 型企業、永續敘事是綠藤的，不是我們的）。
> 這份 DNA 來自對綠藤官網、部落格熱門文章、品牌識別報導與成長案例的實際拆解。

## 一、品牌世界觀（他為什麼會這樣想）

綠藤的所有語言都從一個核心信念長出來：

> **The more we know, the less we need.**
> 當我們了解越多，需要的越少——保養亦是。

由此展開的思想結構：

1. **減法哲學**：「沒有減法，何來精華」「對的，不用多」。減去 2,700 種非必要成分，把保養簡化成「一水一油」兩步驟。十年只出 23 支產品——克制本身就是主張。
2. **知識即善意**：品牌相信「更多知識、更多透明、更多表裡如一」才能帶來「更少浪費、更少衝動、更少非必要」。所以教育不是行銷手段，是品牌存在的理由——行銷只是順便發生。
3. **真實**：全成分揭露、實驗數據、公平貿易來源都攤開講；不完美也講（哪些人不適用、什麼情況要就醫）。
4. **永續是體質不是活動**：B 型企業、1% for the Planet、再生玻璃瓶器、公開永續報告書。永續敘事貫穿產品頁到企業頁，不是行銷檔期。

> **MAPOROO 的對照**：我們的核心信念不是「減法」而是「不二選一」（有效與舒適可以並存）。
> 學它「教育先於銷售」的紀律，但不要把減法哲學搬過來——我們有 15 支商品、5 個系列，克制感要從**秩序**來，不是從**數量少**來。

## 二、語言指紋（他怎麼說話）

### 標題公式（**這一條 MAPOROO 直接沿用**）

熱門文章的標題幾乎都是同一個骨架：

```
（症狀/困擾的疑問句）？（破除迷思的提醒）、（數字化的行動建議）
```

實例（皆為官網實際標題結構）：

- 「私密處長痘痘原因？外陰顆粒別擠、3 情況要就醫，私密清潔保養 5 招」
- 「囊腫型痘痘怎麼辦？3 個照護技巧避免留疤」
- 「物理防曬、化學防曬差在哪？3 步驟找到適合你的防曬」

公式拆解：**疑問句共鳴（你正在搜尋的困擾）→ 別亂做（別擠、別誤信）→ 數字承諾（3 情況、5 招）→ 就醫提醒（負責任的邊界）**。

這個公式同時是 SEO 武器與合規保險：疑問句吃搜尋意圖、數字建議吃精選摘要、就醫提醒守住醫療邊界。

### 句式特徵

- **先同理，再科普，後建議**：開頭描述讀者的處境，中段講成因與機轉，結尾給可實踐的步驟清單
- **數字化**：3 個原因、5 個方法、7 個步驟——把模糊的建議變成可執行的清單
- **溫柔的祈使句**：「建議先觀察」「不妨試試」「記得讓肌膚休息」——不命令、不恐嚇
- **誠實的邊界句**（品牌護城河，必學）：「若持續未改善，建議諮詢皮膚科醫師」
- **成分講原理不講神效**：講成分與機轉，不說「治好」「根除」

### 詞彙表

| 常用（多用） | 迴避（不用） |
| :-- | :-- |
| 純淨、減法、真實、透明、溫和、永續 | 奇效、秒殺、爆款、狂銷、逆天 |
| 建議、不妨、可以試著、有助於 | 保證、根治、治癒、消滅、一次見效 |
| 肌膚、頭皮、髮絲（身體部位講得精確） | 嫩白到發光、吹彈可破（浮誇修辭） |
| 全成分、實證、機轉、來源 | 獨家秘方、神秘配方 |
| 你（面對讀者永遠用「你」，像朋友） | 各位親、寶寶們、姐妹們 |

## 三、內容鐵律（他為什麼能同時教育與銷售）

官網每一篇文章至少符合**三大目的之一**：教育消費者、強化品牌、增加銷售。
內容品質三準則：**資訊正確性、給讀者的價值（理念／新知／可實踐／正向情緒）、具體建議**。

商品置入的手法（拆解自熱門文章）：

1. 文章 90% 篇幅誠實解決問題，商品只出現在「解法清單」的其中一項
2. 置入時講**成分與適用情境**，不講療效
3. 文末以「延伸閱讀」與「相關商品」雙軌導流——教育迴圈與銷售迴圈並行
4. 該就醫的症狀，直接請讀者就醫——短期少賣一單，長期贏得信任（也守住法規）

> [!CAUTION]
> **第 1–3 點 MAPOROO 不採用。**
> 綠藤仍然在文章裡置入商品與商品連結；MAPOROO 選了更徹底的路——**部落格零商品置入**
> （老闆 2026-08-05 拍板，見 `maporoo-brand-dna.md` 第三節）。
> 這一節請只當作「別人怎麼做」的參考資料，**不要照著寫**。
> 我們沿用的是第 4 點（誠實邊界）與整套標題公式、四段式結構。

## 四、視覺與影音風格（僅作方法參照）

綠藤的識別是「Nature's Code 自然密碼」：綠色漸層、自然數學、再生玻璃材質敘事。

**MAPOROO 不抄這一套**——MAPOROO 的視覺是紙感米白 ＋ 暖調近黑 ＋ 細線分隔 ＋ 緊湊排版（見 `maporoo-brand-dna.md` 第四節）。

值得學的是**方法**：

- 有一組靜音去 logo 也認得出來的視覺常數
- 攝影拍真實質地，不拍修圖廣告臉
- 社群走知識卡片式，資訊有秩序
- 影音語速沉穩、旁白解說感、開頭同理不恐嚇
